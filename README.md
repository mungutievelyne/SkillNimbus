# SkillNimbus ☁️

**Learn smarter. Practise confidently. Track your progress.**

SkillNimbus is an independent, unofficial AZ-900 exam preparation web application designed to help learners study Microsoft Azure Fundamentals through interactive quizzes and a simple, user-friendly learning experience.

The project aims to make cloud computing concepts easier to understand, help learners identify areas for improvement, and build confidence before taking the AZ-900 certification exam.

## ✨ Features

### 🧠 Smart Quiz
- Practise Azure Fundamentals concepts through interactive multiple-choice questions.
- Select answers and receive feedback to support learning.
- Reinforce understanding of cloud computing concepts.

### 🎨 User-Friendly Interface
- Built with a responsive, modern interface.
- Switch between light and dark themes for a more comfortable study experience.

### 🤖 AI Study Buddy
- Planned learning companion to help explain cloud concepts in simpler language.
- Intended to support learners as they revise unfamiliar topics.

### 📊 Readiness Tracker
- Planned progress-tracking feature to help learners understand their study progress and identify topics that need more revision.

> **Development note:** The Smart Quiz and theme-switching interface are implemented. The AI Study Buddy and Readiness Tracker should be marked as available only when their functionality is complete and working.

## 🛠️ Technology Stack

- **React** — building the user interface.
- **TypeScript** — adding type safety to the application.
- **Vite** — development server and build tooling.
- **CSS** — styling and interface presentation.

## 🚀 Getting Started

Follow these steps to run SkillNimbus on your computer.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm, which is included with Node.js
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd SkillNimbus
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### Production Build

To create a production build, run:

```bash
npm run build
```

If the project includes a configured preview script, you can preview the build using:

```bash
npm run preview
```
